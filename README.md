# 🎮 Tic Tac Toe Multiplayer

🎮 A modern real-time multiplayer Tic Tac Toe game built with Flutter & Firebase for Android and Web. Create private rooms, challenge friends online, join live lobbies, or watch matches as a guest spectator — all with seamless real-time gameplay ⚡


## ✨ Features

- ✅ Real-time multiplayer gameplay
- ✅ Create & join custom rooms/lobbies
- ✅ Guest spectator mode
- ✅ Cross-platform support (Android + Web)
- ✅ Firebase backend integration
- ✅ Responsive Flutter UI
- ✅ Smooth gameplay experience
